# THE ALT SPACE — Interactive Event Invitation

A simple, standalone, mobile-first interactive playing card invitation for **THE ALT SPACE** ([@thealtspace._](https://www.instagram.com/thealtspace._?srtk=ZGtmZXY0enBidXRk)), faithfully recreating the viral party card deck invitation from [this Instagram reel](https://www.instagram.com/reel/De6Xl6bIO4S/).

---

## 🎴 Key Features

### 1. Host Event Customizer Section (`Edit Event` Button)
The host can click **"Edit Event"** in the top navigation bar to customize:
- **Event / Party Name** (e.g. *Diwali Soirée*, *Kabir's Birthday Bash*)
- **Venue / Avenue Location** (e.g. *Villa 9, Alibaug*, *The Secret Loft @ Bandra*)
- **Date & Time Picker**: Live calendar date & time selector that automatically recalibrates the real-time countdown timer!
- **Host WhatsApp Contact**: The host's real phone number — all guest RSVPs and directions requests are sent directly to this number!
- **Drinks & Dress Code Policies**: (e.g. *BYOB*, *Traditional mandatory*)
- **Shareable Link Generator (`Copy Shareable Link`)**: Automatically encodes the host's event details into a shareable URL (`?event=...&venue=...&date=...&phone=...`) so guests opening the link see the host's exact event details!

---

### 2. The 8-Card Interactive Flow
1. **Card 0 (Deck Cover)**: "Tap the deck to reveal" with stacked card 3D depth and glowing Diya.
2. **Card 1 (The Ace `A ♦`)**: Concept & story card with quote box and *"Open The Plan →"*.
3. **Card 2 (The King `K ♦`)**: Schedule details (Date, Time, Venue, BYOB) + instant **"Add to Google Calendar"** button.
4. **Card 3 (The Queen `Q ♦`)**: Live ticking countdown timer (**DAYS**, **HRS**, **MIN**, **SEC**).
5. **Card 4 (The Jack `J ♦`)**: Rulebook with ₹200 rulebreaker penalty badge.
6. **Card 5 (Card 10 `10 ♦`)**: Guest intake name input + attendance buttons (*Pakka 🔥*, *Shayad 🤔*, *Iss baar not possible 💔*).
7. **Card 6 (Card 9 `9 ♦`)**: 8 Crew Squad roles with live witty quote feedback.
8. **Card 7 (VIP Pass `★ ♦`)**:
   - Generates a personalized VIP card with guest initial badge, name, and chosen role.
   - **"Deal me in on WhatsApp"**: Pre-fills an instant RSVP message to the host's WhatsApp number and triggers confetti!
   - **"Download My VIP Pass"**: Renders and downloads the high-res pass image.
